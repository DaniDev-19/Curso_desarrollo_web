Objetos, JSON y manejo de datos

En JavaScript, los objetos permiten organizar información en estructuras claras y reutilizables. El JSON es un formato estándar para intercambiar datos entre sistemas y aplicaciones web.

Objetos JSON
Objetos JSON Fetch

¿Qué es un objeto?

Un objeto es una colección de propiedades y métodos. Permite agrupar información relacionada en una sola unidad. 

const persona = {
  nombre: 'Ana',
  edad: 20,
  saludar() {
    console.log('Hola');
  }
};

Propiedades y métodos

Las propiedades guardan valores, mientras que los métodos ejecutan acciones. 

console.log(persona.nombre);
persona.saludar();

Objetos y acceso a datos

Acceso con punto

console.log(persona.edad);

Acceso con corchetes

console.log(persona['nombre']);

Modificar propiedades

persona.edad = 21;

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto ligero usado para representar datos. Se utiliza muchísimo para enviar y recibir información entre un servidor y una página web. 

{
  "nombre": "Carlos",
  "edad": 25,
  "activo": true
}
JSON usa comillas dobles para las claves y valores de texto, y puede contener cadenas, números, booleanos, arreglos u objetos.

Fetch y peticiones HTTP

¿Qué es fetch?

Fetch permite realizar peticiones a un servidor desde JavaScript. Es la base para obtener datos de una API. 

fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(res => res.json())
  .then(data => console.log(data));

¿Por qué se usan?

Gracias a fetch una página puede cargar información en tiempo real sin recargar toda la página. Esto es muy útil en aplicaciones modernas.

Flujo de una petición

  • Se realiza una petición al servidor.
  • El servidor responde con datos.
  • JavaScript convierte esa respuesta a JSON.
  • Los datos se muestran o se procesan.
