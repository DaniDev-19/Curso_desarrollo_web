# Curso de Desarrollo Web

"Aprender Creando, Crear Aprendiendo"

Proyecto práctico que reúne ejemplos y ejercicios de HTML, CSS y JavaScript para aprender desarrollando.

## Objetivo

Este repositorio es un curso en forma de proyecto con ejemplos reales de páginas web y pequeñas aplicaciones. Está pensado para aprender conceptos básicos y prácticos de desarrollo web paso a paso.

Ideal para Aprender las bases y los fundamentos necesarios para adentrase en el mundo del desarrollo web.


## Contenido del proyecto

- `css.html` — ejemplos de estilos con CSS
- `curso.html` — página de presentación del curso
- `javascript.html` — introducción a JavaScript
- `objetos-json.html` — objetos y datos JSON
- `web.html` — estructura de una página web

## Proyectos incluidos

- `Api/` — ejemplo de consumo de API con `fetch`
- `calculadora/` — calculadora interactiva en JavaScript
- `Contador/` — contador con botones y actualización dinámica
- `culebrita/` — juego de la serpiente
- `Reloj/` — reloj digital en tiempo real
- `presentacion/` — página de presentación del curso

## Cómo usar

1. Abre el archivo HTML que quieras ver en tu navegador.
2. Para los ejemplos que usan `fetch` o archivos locales, abre el proyecto desde un servidor local.
   - Recomendado: la extensión `Live Server` de VS Code.
3. Navega por cada proyecto para ver HTML, CSS y JavaScript funcionando juntos.
