¿Cómo funciona todo?

HTML

La estructura se arma con un contenedor principal, un visor del número, botones para sumar, restar y reiniciar, y un campo para cambiar el paso. Cada elemento tiene un id o una clase para que JavaScript pueda encontrarlo. 

<div id="display">0</div>
<button id="incrementar">+1</button>

CSS

El CSS le da estilo al contador: colores, sombras, tamaños, botones y un diseño agradable. También permite que el valor cambie visualmente con una animación. 

.display {
  font-size: 4rem;
  color: #2dd4bf;
}

JavaScript

JavaScript selecciona los elementos del HTML, escucha los clics de los botones, actualiza el valor del contador y muestra el resultado en pantalla. 

document.getElementById('incrementar').addEventListener('click', () => {
  contador += paso;
  actualizarDisplay();
});
