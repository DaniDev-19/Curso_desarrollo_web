Reloj en tiempo real

Este reloj se actualiza automáticamente cada segundo.

00:00:00

Fecha

¿Cómo funciona?

HTML

El HTML define el lugar donde se muestra la hora y la fecha. Se crea un contenedor con un id para que JavaScript pueda encontrarlo fácilmente. 

<div id="reloj">00:00:00</div>

CSS

El CSS le da forma visual al reloj: colores, tamaño, sombra y diseño moderno. 

.clock {
  font-size: 4rem;
  color: #2dd4bf;
}

JavaScript

JavaScript obtiene la hora actual del sistema, la convierte en texto y la actualiza cada segundo utilizando setInterval(). 

setInterval(actualizarReloj, 1000);
